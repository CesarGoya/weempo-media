# weempo-media

Public staging area for images published on [weempo.com](https://weempo.com): article diagrams and featured images.

Claude pushes images here, then imports them into the WordPress Media Library through the browser.

**Only put images here that are meant to be public on the blog.** No documents, student data or anything confidential: this repository is public.

Structure: `images/YYYY-MM/<file>.webp|jpg`
